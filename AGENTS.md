# Notes for agents in Versioncam's public home

This repository is **public**. The Versioncam engine's source is not, and
nothing from it belongs here.

- The docs pages are generated by `scripts/import-docs.mjs` from the
  versioncam package as npm publishes it. Never copy text, code, plans or
  file paths from anywhere else. `src/content/docs/` is gitignored for that
  reason: nothing in it is ever committed.
- Never commit a token, a key, an account id, or a path under anyone's home
  directory.
- `npm run build` must pass before a push; it is what Cloudflare Pages runs.
- Astro's own guidance: https://docs.astro.build — `astro dev --background`
  runs the dev server in the background (`astro dev stop` to stop it).
